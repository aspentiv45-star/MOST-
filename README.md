# MOST

VPN на AmneziaWG с продажей подписок через Telegram.

```
Клиент (AmneziaWG) ──► Сервер в Нидерландах ──► Интернет

Клиентский бот: оплата по скриншоту, выдача конфигов
Админ-бот:      одобрение оплат, клиенты, статистика
```

## Что понадобится

1. **Сервер** (Ubuntu 22.04 / 24.04), root.
2. **Два бота** от [@BotFather](https://t.me/BotFather) (`/newbot` два раза): клиентский и админский.
3. **Ваш Telegram ID** от [@userinfobot](https://t.me/userinfobot).

## Установка

```bash
apt update && apt install -y git
git clone https://github.com/aspentiv45-star/MOST-.git && cd MOST-
sudo bash install.sh \
  --token 'ТОКЕН_КЛИЕНТСКОГО_БОТА' \
  --admin-token 'ТОКЕН_АДМИН_БОТА' \
  --admin ВАШ_ID \
  --pay 'Перевод по номеру +7 900 000-00-00, Т-Банк, Иван'
```

Если у хостинга есть свой файрвол, откройте в нём UDP-порт, который назовёт скрипт.
После установки нажмите `/start` в обоих ботах.

## Как это работает для клиента

Каждый конфиг (одно устройство) — отдельная подписка: 200 ₽ за 30 дней.

1. «➕ Купить конфиг — 200 ₽» → реквизиты → клиент присылает скриншот.
2. Скриншот приходит в админ-бот с кнопками «✅ Одобрить» и «❌ Отклонить».
3. После одобрения клиенту сразу приходит новый конфиг на 30 дней. Второе устройство — ещё одна покупка.
4. «📄 Мои конфиги»: у каждого конфига свой срок и кнопки «⬇️ Скачать», «🔄 Продлить — 200 ₽», «🗑 Удалить».
5. За 3 дня и за 1 день до конца бот напоминает про конкретный конфиг. Когда срок вышел, конфиг удаляется
   с сервера: VPN через него перестаёт работать. После продления тот же файл снова работает, переустанавливать не нужно.

Один клиент может держать до 3 конфигов (`--max N` в `install.sh`). Конфиги администратора бессрочные.

## Админ-бот

Кнопки:
- **⏳ Оплаты**: неразобранные скриншоты с кнопками «Одобрить» и «Отклонить». В каждой оплате видно,
  за что она: новый конфиг или продление конкретного.
- **👥 Клиенты**: все конфиги со сроками, у каждого кнопки «➕ 30 дней» и «⛔️ Отключить».
- **🎁 Выдать конфиг**: пришлите ID клиента (и число дней), и он бесплатно получит новый конфиг.
- **📊 Статистика**: оплаченные конфиги, выручка, кто подключался и сколько трафика.

Команды: `/send ID текст` (написать клиенту), `/broadcast текст` (написать всем).

Если что-то сломается, например не получится создать конфиг, текст ошибки придёт в админ-бот.

Реквизиты хранятся в `/etc/most/pay.txt`. Их можно менять в любой момент, перезапуск не нужен.

## Российские сайты с включённым VPN

Конфиги собираются с раздельным туннелем: российские сети идут напрямую, с IP устройства клиента,
а всё остальное — через Нидерланды. Банки, Госуслуги и маркетплейсы работают с включённым VPN.

Бот раз в сутки скачивает свежий список российских сетей. Российские адреса в туннель не попадают никогда;
чтобы конфиг остался компактным (до 2000 сетей), напрямую идут и мелкие зарубежные промежутки между ними
(около 5% зарубежных адресов). Такой конфиг не помещается в QR-код, поэтому бот присылает только файл.

Проверить, как пойдут конкретные сайты: `python3 bot/split.py`. Размер списка: `SPLIT_LIMIT=1000`
в `/etc/most/bot.env` (меньше — короче конфиг, но больше зарубежных адресов идёт напрямую).
Чтобы получить конфиг с обновлённым списком, клиенту достаточно скачать его заново в «📄 Мои конфиги».

Отключить раздельный туннель (весь трафик через VPN): добавьте `SPLIT_RU=0` в `/etc/most/bot.env`
и выполните `systemctl restart most-bot`.

## Обход белых списков (вход через РФ)

Когда включены белые списки, мобильный интернет пропускает только разрешённые адреса.
Нужен «вход»: российский сервер, IP которого в этих списках есть (например, Yandex Cloud или VK Cloud).
Он ничего не шифрует и не хранит, а только пересылает трафик на основной сервер.

```
Клиент ──► вход (Yandex Cloud) ──► основной сервер NL ──► Интернет
```

1. На **сервере-входе** (Ubuntu), где ПОРТ — UDP-порт AmneziaWG основного сервера:
   ```bash
   apt update && apt install -y git
   git clone https://github.com/aspentiv45-star/MOST-.git && cd MOST-
   sudo bash relay.sh --to IP_ОСНОВНОГО:ПОРТ
   ```
   В облаке разрешите этот UDP-порт в группе безопасности.
2. На **основном сервере**:
   ```bash
   cd MOST- && git pull && sudo bash install.sh --relay IP_ВХОДА
   ```

Теперь бот выдаёт два файла: `vpn1.conf` (напрямую) и `vpn1-wl.conf` (через вход).
Уже выданные конфиги клиент может скачать заново в «📄 Мои конфиги», ключи останутся прежними.

Гарантии нет: списки у операторов разные и меняются. Прежде чем обещать клиентам обход,
проверьте `-wl` конфиг на мобильном интернете при включённых списках.

## Обслуживание

```bash
git pull && sudo bash install.sh --token ... --admin-token ... --admin ...   # обновить, клиенты сохраняются
journalctl -u most-bot -f        # логи ботов
awg show                         # подключения
sudo bash uninstall.sh           # удалить (с резервной копией)
```

## Безопасность

- Токены, ключи и база клиентов хранятся только на сервере: `/etc/most/`, `/var/lib/most/`, `/etc/amnezia/amneziawg/`.
- Репозиторий публичный, ничего секретного в него не добавляйте.
